# TLE92466ED Driver API reference {#mainpage}

The classes, types and registers of the driver for the Infineon TLE92466ED six-channel low-side solenoid driver,
generated from the headers in `inc/`.

Start with tle92466ed::TLE92466ED, the driver, and tle92466ed::SpiInterface, the base of the port you write. Errors are
tle92466ed::Error inside tle92466ed::Result; the configuration is tle92466ed::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">TLE92466ED Driver
documentation</a>.
