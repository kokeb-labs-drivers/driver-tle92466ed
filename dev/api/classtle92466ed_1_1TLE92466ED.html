Detailed Description

template<SpiPort Port>
class tle92466ed::TLE92466ED< Port >

Driver for one TLE92466ED on a platform port.

Lifecycle: construct with the configuration (no I/O), then EnsureInitialized(), the one way to start (reset, readiness, identity, start-up faults, every register), which leaves the chip in Config Mode; EnterMissionMode() lets the channels switch. Every call that touches the chip returns Error::NotInitialized until EnsureInitialized() has succeeded; no call starts the chip as a side effect.

Optional port hooks, found at compile time:

Hook Used for Without it
void DelayUs(uint32_t us) noexcept t_POR, t_RESN, the INIT_DONE and self-test polls Compile error: the waits are required
bool GpioSet(CtrlPin, GpioSignal) noexcept RESN pulse at start-up, EN with the operation state, DRV0/DRV1 Start-up waits t_POR and rewrites every register; HardwareReset() and SetDrivePin() return Unsupported
bool GpioRead(CtrlPin, GpioSignal&) noexcept ReadFaultPin() ReadFaultPin() returns Unsupported
void Log(LogLevel, const char* message) noexcept One line per lifecycle event or start-up failure Nothing is logged

A hook declared with the wrong signature (for example void GpioSet(...)) is a compile error.

◆ EnsureInitialized()

template<SpiPort Port>
Result< void > tle92466ed::TLE92466ED< Port >::EnsureInitialized ( )
noexcept

Start the chip, once: the only way to initialise the driver.

In order: check the configuration; bring the port up; reset the chip (EN low, RESN low for kResetPulseUs, then t_RESN; without GpioSet() write CH_CTRL to 0 at once, so a chip an earlier run left in Mission Mode is switched off, then wait t_POR, section 4.1.3); poll FB_STAT until INIT_DONE = 1, at most Config::init_timeout_us (4.2.1); check ICVID (manufacturer 0xC1, version A11 or A13); write CH_CTRL to Config Mode with every channel off; read, keep (GetStartupFaults()) and clear the diagnosis flags it found, refusing an unprogrammed OTP (4.9.7); write CLK_DIV and wait for INIT_DONE again; write GLOBAL_CONFIG with the SPI watchdog off and read it back; write VBAT_TH, FAULT_MASK0..2, the pairs and every register of every channel that is not an enabled pair's slave; write WD_RELOAD, and last, with Config::spi_watchdog, GLOBAL_CONFIG with SPI_WD_EN, read back (5.2.2); then arm the reset watch if POR_EVENT and RES_EVENT read 0 (4.1.1). It ends in Config Mode. 181 frames on a clean chip with every channel written, plus the reset; later calls return Ok at once with no I/O. After a failure the driver stays uninitialised and the next call starts again from the beginning.

Returns
Ok, InvalidArgument (no I/O), Bus, Timeout, DeviceIdMismatch, DeviceFault (OTP_VIRGIN), WriteMismatch (GLOBAL_CONFIG), or a reply error (NoDevice, CriticalFault, Crc, ReplyMismatch, FrameRejected).

Set a channel's average current setpoint (SETPOINT.TARGET, section 4.6.1).

The current is checked against the operating range, never clamped (handbook KB-CPP-126): up to 1.5 A, and with the configured dither amplitude up to 1.8 A; for the master of a pair, up to 2.7 A with dither (Table 14). With dither, a non-zero setpoint must exceed the amplitude (section 4.7.1). The value is rounded to the nearest TARGET count; the call returns what was programmed. Allowed in either state: the channel switches when it is enabled in Mission Mode.

Parameters
channelThe channel; not a slave.
microampsThe setpoint.
verifyReadBack: read SETPOINT back, two more frames.
Returns
The programmed current in microamps, or NotInitialized, InvalidArgument, WrongState (a slave), WriteMismatch, Bus or a reply error. Two frames.

Switch channels on and off together. CH_CTRL is read first, so the copy is the chip's (a channel a fault switched off stays off), then written whole with only the EN_CH bits the mask names changed; OP_MODE is kept as the chip has it, never set (handbook KB-CPP-121, -122).

Parameters

A channel already on whose state a failed write left unknown is kept as the chip has it, so the mask still switches the others off; only a channel it newly turns on is refused (WrongState).
verifyReadBack: read CH_CTRL back, two more frames.
Returns
Ok, NotInitialized, InvalidArgument, WrongState (nothing sent), MissionBlocked (the chip left Mission Mode on its own), WriteMismatch (the chip keeps a channel with a latched fault off, section 4.9.2), Bus or a reply error. 4 frames.

Run the OFF-state overcurrent check once (section 4.9.6): set CH_CONFIG.OC_DIAG_EN and the channel's EN_CH; the chip switches the stage on for t_OCon and clears OC_DIAG_EN.
