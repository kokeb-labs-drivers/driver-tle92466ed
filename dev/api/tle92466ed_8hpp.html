Detailed Description

TLE92466ED driver: the one header to include.

tle92466ed::TLE92466ED<Port> drives one Infineon TLE92466ED six-channel low-side solenoid driver through a platform port you write (see tle92466ed_spi_interface.hpp). The driver has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each object one owner, or guard it with one mutex. Section numbers refer to the TLE92466ED datasheet, Rev. 1.2.
