Detailed Description

Public types of the TLE92466ED driver: errors, Result<T>, configuration, decoded status and feedback, and the unit conversions.

Everything here is plain data with no platform dependency, so handlers, tests and tools can include it without the driver template. The configuration defaults are the chip's reset values (TLE92466ED datasheet Rev. 1.2, section 5.3), so Config{} describes a chip that was just reset. Section numbers below refer to that datasheet.
