◆ Error

enum class tle92466ed::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; chip-specific values start at 16. [[nodiscard]] on the type: a function that returns a bare Error cannot have it ignored either (KB-CPP20-037).

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded, Deinitialize() ran since, or the chip was found reset (UnexpectedReset).

InvalidArgument 

An argument or a Config field is out of range; nothing was sent.

Bus 

A port hook (Transfer(), EnsureInitialized(), GpioSet(), GpioRead()) returned false.

Timeout 

INIT_DONE did not read 1 within Config::init_timeout_us (section 4.2.1), or the self-test did not finish (section 4.9.8).

DeviceIdMismatch 

ICVID is not manufacturer 0xC1 with a known version (5.3.2.19).

Crc 

A reply's CRC-8 was wrong, or the chip reported a wrong CRC in the driver's frame (status 00010B, sections 5.1.2 and 5.2.3.3).

Busy 

Not returned by this driver: the chip is never busy to SPI.

DeviceFault 

The chip reports damage: OTP_VIRGIN set at start-up (4.9.7), or an internal bus fault in a reply's status (5.2.3.3).

Unsupported 

The port lacks the optional hook this call needs (GpioSet(), GpioRead()).

NoDevice 

MISO read all zeros, all ones or the frame just sent: nothing drives SO (no chip, no VIO, a loose wire) or MOSI is looped back.

CriticalFault 

The chip answered with a critical fault frame (5.2.3.5), twice in a row: it is in the Critical Fault state; GetLastCriticalFault() has the flags. EN is driven low and the driver is uninitialised: only a power-on reset or RESN leaves that state (Figure 4).

ReplyMismatch 

A reply with a valid CRC that does not answer the request: wrong reply mode or width, wrong R/W echo, or the anchor read did not answer as expected (a frame lost or added on the bus).

FrameRejected 

The chip reported an SPI frame error or a write to a read-only register in its reply status (5.2.3.3); the frame was ignored.

WrongState 

The call needs the other operation state (Config Mode or Mission Mode, section 4.3.1), or the channel is the slave of a parallel pair, or it depends on a register an earlier failed write may have changed (docs/contract.md, "Ambiguous writes"). Nothing was sent.

MissionBlocked 

EnterMissionMode() found a fault that keeps the chip in Config Mode (Figure 4) or INIT_DONE = 0, or the chip refused OP_MODE; or an enable found the chip back in Config Mode on its own.

WriteMismatch 

A register read back differs from what was written: at start-up, or with Verify::ReadBack. The chip did not take the write.

NotReady 

No feedback to report: no new values (FB_UPD = 0) or no measurement period (TP_MANT = 0, section 4.10.2).

UnexpectedReset 

The chip reset since the start (POR_event or RES_event in FB_STAT, section 4.1.1). EN is driven low and the driver is uninitialised.
